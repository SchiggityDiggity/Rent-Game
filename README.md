# Rent-Game

## Description:

A simple endless game with many diverse options! Utilizing AI as a guide/tutor, this simple text-based game became a repeatable and wacky game with many twists and turn to never leave you with the same outcome!


## Features & Note:

### Features
- 3 Games: Black Jack, Rock Paper Scissors, Dice Rolling
- Pray choice: 12 different outcomes
- 6 Choices to make $$$
- And more to be discovered...

### Note:

The use of AI in this personal project was solely used to steer the builder (Me) in the right direction; with it providing hints and feedback to help me create a fun little game. AI did not feed me code where I simply copied and pasted it, the code was typed by the builder and will continue to be typed by the builder himself. The ideas came from the builder, with AI playing a minute role in idea generation and coding.

All that being said, this was a fun little project that may be worked on more in the future, and this helped build upon my python skills in a fun way!
